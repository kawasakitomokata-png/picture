# picture — 加工用の写真置き場

ブログ／SNS 投稿用の画像を、加工前と加工後で分けて保管するリポジトリです。

## フォルダの使い方

| フォルダ | 用途 |
| --- | --- |
| `input/` | **加工してほしい写真をここに入れる**（自分でアップロードする場所） |
| `output/` | 加工後の写真が入る場所（Claude が書き戻す） |

## 写真のアップロード手順

### パソコンから

1. このページで `input` フォルダを開く
2. 右上の **Add file → Upload files**
3. 写真をドラッグ＆ドロップ（複数枚まとめて可）
4. ページ下の **Commit changes** を押す

### スマホから

GitHub アプリではなく、ブラウザ（Safari / Chrome）で github.com を開いて同じ手順で操作します。
アプリからは画像のアップロードができません。

## 依頼のしかた

アップロードしたら、Claude にこう伝えます。

> picture リポジトリの input に写真を上げました。◯◯風に加工してください

加工後の画像は `output/` にコミットされます。

## 注意点

- ブラウザからのアップロードは **1ファイル 25MB まで / 一度に 100 ファイルまで**
- iPhone の `.HEIC` 形式は GitHub 上でプレビューできません。
  設定 → カメラ → フォーマット → **「互換性優先」** にすると JPEG で保存されます
- **このリポジトリは Public（公開）です。** 見られて困る写真は置かないでください。
  非公開にする場合は Settings → 一番下の Change visibility から Private に変更できます
